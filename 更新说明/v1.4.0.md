- 新增多窗格布局：终端区最多同时放 4 个会话窗格，每个窗格都能直接输入；从侧栏把会话拖到窗格的上下左右边缘即可拆分，拖到中央则替换，拖入已在别的窗格的会话会移过去
- 窗格之间的分隔条可拖动调整大小（拖动时显示两侧列数），双击恢复等分；窗格头可向右 / 向下拆出新窗格、最大化或关闭，关闭窗格不会结束会话
- 焦点窗格即当前选中的会话，快捷键、审批、属性面板、终端搜索与导出都跟随焦点；Ctrl+Alt+方向键在窗格间移动焦点，Ctrl+Shift+M 最大化 / 还原当前窗格
- 非焦点窗格里的会话等待批准时，窗格头变橙并显示一条「拒绝 / 允许」批准条，不用切过去也能直接处理
- 多窗格时属性面板自动收起；改动、收尾等视图仍占满详情区，按 Esc 返回窗格网格；窗口太窄、窗格不足 60 列 × 12 行时自动只显示焦点窗格，变宽后恢复
- 窗格布局在重启后自动恢复：待续接的会话在窗格内显示续接卡片，已不存在的会话留下空位并注明原会话名
- 新增会话预设：新建表单可「存为预设」，保存工作目录、独立工作区选项与首条提示词；首页「预设 ▾」与命令面板一键按预设创建会话，设置页可改名与删除
- 改动 diff 支持忽略空白差异：工具栏按钮或按 I 切换，只有空白变化的文件会给出说明，文件列表与增删统计保持不变
- diff 支持跳转外部编辑器的指定行：在设置页配置编辑器命令（内置 VS Code / Cursor / JetBrains 预设），悬停 diff 行点「:行号」即可在编辑器中打开对应位置
