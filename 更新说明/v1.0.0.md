- 新增「会话续接」：进程退出、面板重启或会话结束后可接着同一段对话继续，支持全新开始、分叉为新会话，退出时可选择保留会话，下次启动自动或询问后续接
- 新增「用量与上下文」：会话行显示上下文占用与累计花费，属性面板按 token 类别、模型、子代理拆分，支持今日总计、每日预算与超额提醒
- 新增「改动批注」：在 diff 上按行写修改意见，一次发给该会话的 Claude；Claude 正忙时可排队，本轮结束后自动发出
- 新增「撤销单个文件」：改动页里撤销某个文件的改动，撤销前自动备份，可一键恢复
- 新增「工作区收尾」标签（Ctrl+Shift+F）：在面板里完成提交、合并、推送与创建 PR，合并冲突时可开一个自动带上冲突文件清单的解决冲突会话
- diff 视图支持语法高亮、词级差异与左右分栏（改动页按 V 切换）
- 新增终端内搜索（Ctrl+F）与终端输出导出（纯文本 / 原始 ANSI）
- 新建会话可填写多行首条提示词，Claude 就绪后自动提交；新增提示词模板（Ctrl+Shift+T），支持变量自动填充
- 新增「批量派发」：同一任务派发给多个独立工作区并排对比，保留满意的方案并一键清理其余
- 新增「每轮自动验证」：每轮结束后自动运行配置的测试命令，失败输出可一键发给 Claude 修复
- 新增「会话历史」（Ctrl+Shift+H）：搜索、过滤、续接、固定已结束的会话，可调整保留策略
- 新增「活动时间线」（Ctrl+Shift+L）：所有会话的事件按时间排成一条线，离开回来一眼看清发生了什么
- 新增「远程通知」：离开电脑时把等待批准、本轮结束、出错、预算告警推送到企业微信、钉钉或飞书群机器人
- 修复删除或清空的会话历史在重启后又以「旧版迁移」出现的问题
- 快捷键展示统一使用 ⇧ 符号
