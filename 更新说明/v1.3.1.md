- 改动页加宽代码区：进入改动页自动收起属性面板，切回终端时按原来的设置自动展开；改动页里仍可随时手动展开
- 文件列表可拖动调宽（双击分隔条恢复默认）、可整列收起（B 键或 diff 标题左侧按钮），宽度与收起状态都会记住
- 新增专注审阅（F 键或工具栏按钮）：收起会话列表与属性面板，改动内容占满工作区，按 Esc 退出
- 新增自动换行（W 键或工具栏按钮，默认关闭）：长行折行显示不再横向滚动，续行缩进并在行首标出 ↩
- diff 标题栏精简为一行：显示文件相对路径与增删统计，点击路径复制完整地址，右侧新增上一个 / 下一个文件按钮与序号，焦点在 diff 区时 J / K 也能切换文件
- 代码区字号、行高与行号列收紧，同样宽度能显示更多内容；分栏视图在 diff 区不足 640px 时自动按统一视图显示
- 改动页的单键快捷键（V / W / F / B / J / K）只在焦点不在终端和输入框时生效，不会误吞终端输入
