- 新增「独立工作区」：新建会话时勾选即为该会话创建专属 git 工作区（独立分支），多个会话同时改同一仓库互不干扰，主目录保持干净
- 新建表单自动识别 git 仓库，主目录有未提交改动时提示「这些改动不会带入新工作区」；可自定义分支名与基线
- 结束工作区会话时可选择保留或删除工作区；有未提交文件或未合并提交时二次确认并列出数量
- 会话已结束但仍保留的工作区可在命令面板（Ctrl+K）中一键清理，不会无声堆积
- 面板重启后认领的会话完整保留工作区信息（分支、基线、路径）
- 新增「改动」标签页：会话详情可在终端与改动之间切换（Ctrl+Shift+D），左侧改动文件列表，右侧带行号的增删着色 diff
- 改动统计在 Claude 每轮结束后自动刷新，会话列表与属性面板实时显示文件数与 +/− 行数
- 工作区会话可在「相对基线」（含已提交内容）与「仅未提交」两种口径之间切换
- 支持新增 / 修改 / 删除 / 重命名 / 未跟踪 / 冲突等状态，中文文件名、二进制文件、超大 diff、非 UTF-8 文件都有明确提示
- 改动文件可一键用默认程序打开或在资源管理器中定位；多个普通会话共用同一目录时提示改动可能来自其他会话
- 修复窄窗口下详情页头的会话名被挤成一个字的问题
